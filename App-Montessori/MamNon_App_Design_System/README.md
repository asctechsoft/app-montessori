# Bắt đầu sử dụng

1. Mở START_HERE.html bằng trình duyệt để xem bảng mẫu và toàn bộ hướng dẫn. File chạy offline, không cần cài thư viện.
2. Đọc DESIGN_SYSTEM.md để tra thông số và quy tắc nghiệp vụ trên giao diện.
3. Dùng tokens.json làm nguồn giá trị chính. tokens.ts và tokens.css là bản xuất tương ứng.
4. Đọc component-contracts.ts và phần Codebase trong hướng dẫn để triển khai adapter mobile.
5. core-examples.mjs là hàm lõi mẫu có thể chạy bằng Node; không phải app hoặc package UI sẵn để phát hành.
6. validation.json ghi kiểm tra số liệu, contrast và file. Cần QA app thật, font thật và thiết bị thật sau khi lập trình.

Không có font, icon hoặc ảnh trẻ thật trong gói. Không có API key, thông tin tài khoản, SDK hoặc gói phụ thuộc cần cài. Chưa bao gồm dark mode, Figma editable hay ứng dụng native đã hoàn thiện.
